# arkel-lahi

Source code for my personal website: who I am, the services I offer, and how to reach me.

**[Visit the live site](https://arkel-lahi.vercel.app)**

## Pages

- **Home:** hero, skills, experience highlights, services, and contact sections
- **About**, **Services**, **Contact**
- Floating call-to-action and mobile navigation

## Tech stack

Next.js (App Router) · TypeScript · Tailwind CSS · shadcn/ui (Radix) · Framer Motion · Vercel

## How it is built

- All text content (profile, services, highlights) lives in one file, [`content/data.ts`](content/data.ts), so the site can be updated without touching components.
- Sections are separate components in [`components/sections/`](components/sections/).
- Page transitions, a typewriter effect, and light/dark theme support.
- SEO metadata, `sitemap.xml`, and `robots.txt` are generated by Next.js.

## Run locally

```sh
pnpm install
pnpm dev
```

Open http://localhost:3000.
